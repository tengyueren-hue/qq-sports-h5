# QQ运动周报原型

入口：[交互预览](./index.html)，[直接进入插件页](./plugin.html)。

- 基础页面沿用QQ运动模板；新增周报和分享页面按Figma实现，仅包含周报。
- 插件入口进入首页并自动拉起弹窗，上滑将同一份报告展开为全屏。
- 预览支持红点当天、穿戴设备和全部达标三组状态开关。
- 红点当天通过今日卡片中的周报条进入；非红点当天保留独立周报卡，今日卡片依次展示运动、捐步、好友点赞。
- 无穿戴时隐藏03模块；全部达标时保留02模块，收起底部统计和去充能区域。首页承接自动打开的报告弹窗。
- 使用设计示例数据；分享、二维码、登录、补卡、定时触达和数据刷新未接入真实服务。
- 文案只区分有数据与全部无数据；详细规则见[需求单](./docs/QQ运动周报需求单.md)，[HTML版](./docs/QQ运动周报_TAPD_description.html)。无数据规则为产品规格，当前静态页面展示有数据示例。

更新：2026-10-13。375/390/428宽度的关键交互和入口布局已测试；严格Figma像素验收仍有字体与局部绘制差异，不宣称完全一致。

所有运行资源均在此目录内，可用任意静态HTTP服务器预览。未包含本地开发路径、测试截图或凭证配置。
