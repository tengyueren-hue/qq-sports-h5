## 【一句话摘要】

为QQ运动用户提供每周运动总结，通过插件触达、轻量阅读和成绩卡分享，直观呈现一周的运动积累。

## 【需求背景】

QQ运动当前以每日步数、目标和排名为主，用户需要统一回顾一周的运动积累。穿戴设备用户还有活动、锻炼、站立及运动记录，可在周期报告内集中呈现。本次通过周报连接数据总结、轻量阅读和社交分享。

## 【需求目标】

- 汇总周内每日步数、目标完成情况、好友对比和运动表现。
- 通过插件周报内容项，让用户便捷发现周报。
- 通过同一份内容的底部弹窗与全屏阅读，降低进入成本。
- 根据实际数据展示运动类型、次数、时长及穿戴概览。
- 提供静态分享成绩卡及二维码回流。

## 【期望上线时间】

### 2. 需求详细逻辑描述

#### 一、生成、发送与数据更新

| 规则 | 说明 |
| --- | --- |
| 时区 | 北京时间（Asia/Shanghai） |
| 统计周期 | 上周一00:00至本周一00:00，按完整自然周统计 |
| 发送时间 | 每周一08:00生成并发送周报插件消息 |
| 触达方式 | 插件消息及红点 |
| 消息标题 | 上周运动周报 |
| 日期展示 | {开始月日}–{结束月日}，跨年时展示年份 |
| 数据更新 | 用户每次打开周报时，重新加载对应统计周的最新数据 |

#### 二、插件页内容项

1. 增加独立周报消息卡：报告图标、“上周运动周报”、统计日期、“查看周报”及箭头。发送时间沿用消息时间展示。
2. 在现有内容卡提示区增加“上周运动周报 / 去查看”，与独立消息卡指向同一期报告。
3. 提示区保留三项：周报、今日运动、捐步。三项占满同一内容宽度，左侧内容和右侧操作分别对齐。
4. 点击任一周报内容项后进入运动首页，并自动弹出对应周报。
5. 成功呈现报告后标记该期已读，清除该期周报对应红点。
6. 消息按现有插件消息机制保留；历史消息打开对应统计周的报告。
7. 消息卡高度随内容自适应。进入插件页定位最新消息，卡片与固定底栏间保留约12px间距；列表支持滚动。

#### 三、弹窗与全屏交互

1. 初始以约74%可视高度的底部弹窗展示报告，首页背景保留遮罩。
2. 用户上滑时，弹窗跟随手指逐步增高并吸附至全屏；全屏后继续滚动正文。
3. 弹窗与全屏展示同一份完整报告，保持当前阅读位置。
4. 顶部拖拽区域支持下拉收起，遮罩及关闭按钮可关闭报告。
5. 关闭报告后停留在运动首页；关闭分享后回到报告原阅读位置。

#### 四、报告内容

**1. 头图**

展示用户头像、昵称、统计周日期、头图文案、总步数及较上周变化。头图文案由后台按对应统计周配置，具体内容见第七节。

**2. 步数模块：每一步，都算数**

| 内容 | 展示与计算规则 |
| --- | --- |
| 总步数 | 统计周内每日有效步数之和 |
| 日均步数 | 总步数÷有效记录天数，四舍五入为整数 |
| 完成目标 | 按每日目标判定的达标天数，与坚持模块一致 |
| 最佳排名 | 周内有效每日好友排名中的最佳名次 |
| 好友对比 | 展示周步数超过好友的比例及周排名；超过比例=步数低于本人的可比较好友数÷可比较好友数，分母仅统计好友，同分按并列处理 |
| 每日步数 | 按周一至周日展示7天的每日步数 |
| 活力日 | 展示本周步数最多的日期及该日有效好友排名，并列时取较早日期 |
| 较上周变化 | 两周数据可比且上周总步数大于0时，计算步数变化比例；相同时展示“与上周持平” |
| 估算信息 | 复用现有步数距离、跑道圈数及活动消耗估算能力，展示对应估算数值和说明 |

好友对比、环比和估算字段按实际可用数据展示。

**3. 坚持模块：坚持，正在发生**

1. 按周一至周日展示日期、每日步数及达标图示。
2. 展示达标天数、中断天数、最长连续达标天数，复用现有目标及补卡统计口径。
3. 存在可补日期时展示“充能补卡”操作，进入现有充能补卡流程。
4. 补卡完成返回后刷新该周的达标数据。

**4. 运动模块：运动，不止一种方式**

| 内容 | 展示规则 |
| --- | --- |
| 穿戴概览 | 按设备实际数据展示设备名、活动、锻炼、站立及三环图标 |
| 运动汇总 | 展示本周运动次数、总时长、累计消耗 |
| 高光运动 | 展示本周代表性运动及对应数据；有可靠个人最佳记录时展示“个人最佳”标签 |
| 本周运动日 | 按周一至周日展示运动日图示，至少有一条有效运动记录的日期计为1天 |
| 运动类型 | 展示类型数，以及各类型的图标、名称、次数或时长 |
| 好友对比 | 按实际可用的运动类型好友比较数据展示 |

各类运动均按照实际运动数据展示。运动记录按开始时间所属日期归入统计周，沿用现有记录去重和统计能力；总次数、总时长与类型明细保持一致。

**5. 收尾卡片**

展示收尾小标题、鼓励文案和“分享本周运动报告”按钮；报告顶部同时保留分享图标。

#### 五、分享与回流

1. 点击报告顶部分享图标或收尾分享按钮，展示成绩卡预览与QQ分享面板。
2. 成绩卡按设计展示头像、昵称、日期、总步数、日均步数、完成目标天数、最佳排名、周环比、最长连续达标、QQ运动标识及二维码。
3. 分享渠道和操作复用QQ现有分享能力。
4. 二维码对应分享者及该统计周。接收者扫码后可查看分享者该期报告中的统计数据。
5. 接收者点击“查看我的周报”，登录后查看自己的报告。

#### 六、全部无数据兜底

有任意有效数据时，按正常报告展示已有数据，使用对应周配置文案；有效0值按实际值展示。

仅当所有模块均无有效数据时，展示统一空态：

| 位置 | 内容 |
| --- | --- |
| 标题 | 这一周，暂未收到运动记录 |
| 说明 | 有记录后，再来看看你的运动周报吧。 |
| 操作 | 关闭/返回 |

#### 七、后台文案配置

**1. 配置规则**

1. 运营在后台为每个统计周选择并配置头图文案，以统计周开始日期作为对应标识。
2. 同一统计周的有数据用户统一使用该周文案；少量数据按相同规则展示。
3. 查看历史周报时使用对应统计周的文案。
4. 未配置时使用默认头图文案“这一周，你的脚步很有光”。
5. 支持配置头图标题、坚持说明、收尾小标题和收尾正文；数值类文字使用实际数据填充。

**2. 头图文案库**
